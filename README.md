## 🛠️ Panduan Deploy ke GitHub Pages

Workflow GitHub Actions sudah terkonfigurasi di `.github/workflows/deploy.yml`.

1. **Push Semua File ke GitHub**:
   Jalankan perintah berikut di terminal lokal atau export AI Studio:
   ```bash
   git remote add origin https://github.com/fthii9111-bit/K-F.git
   git branch -M main
   git push -u origin main --force
   ```

2. **Aktifkan GitHub Pages**:
   - Buka repositori Anda di `https://github.com/fthii9111-bit/K-F`
   - Masuk ke tab **Settings** (ikon gerigi)
   - Pilih menu **Pages** di sebelah kiri
   - Pada opsi **Build and deployment > Source**, pilih **GitHub Actions**
   - Tunggu proses build selesai di tab **Actions** (~1 menit)
   - Website toko K&F STORE Anda akan live di:
     `https://fthii9111-bit.github.io/K-F/`

---

## 🌐 Deploy Alternatif (Vercel / Netlify - Sangat Mudah)
1. Kunjungi [Vercel.com](https://vercel.com) dan login menggunakan akun GitHub Anda.
2. Klik **Add New...** > **Project**.
3. Import repositori `fthii9111-bit/K-F`.
4. Klik **Deploy** tanpa mengubah konfigurasi. Dalam 30 detik toko Anda live dengan domain gratis `.vercel.app`!
